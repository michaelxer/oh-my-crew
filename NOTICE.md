## Modifications (oh-my-crew by @michaelxer)

This fork makes the following changes to the original software:

1. **Agent Display Names Renamed** - All agents renamed from mythological/cultural references to clean, role-descriptive crew names:
   - Sisyphus → Captain
   - Hephaestus → Strategist
   - Oracle → Sage
   - Librarian → Scribe
   - Explore → Scout
   - Atlas → Foreman
   - Prometheus → Architect
   - Metis → Advisor
   - Momus → Auditor
   - Sisyphus-Junior → Cadet
   - Multimodal Looker → Lookout

2. **Content Filter Compatibility** - System prompt phrasing adjusted to pass through AI proxy content filters (replaced "Powerful AI Agent" with softer alternatives).

3. **Package Identity** - Published as `oh-my-crew` on npm with updated metadata.

All core functionality, architecture, tools, hooks, MCPs, and features remain unchanged from the upstream project.
